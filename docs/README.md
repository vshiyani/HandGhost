# HandGhost Documentation

This directory contains the documentation for the HandGhost project.

## Quickstart

1.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
2.  **Run the Application:**
    ```bash
    python main.py
    ```

For detailed instructions on gestures and settings, see the [Usage Guide](usage.md).

- [Usage](usage.md): How to use the HandGhost application.
